Node Reference

Operator Machine
Any PC or laptop running a modern browser. Reaches the dashboard directly on the LAN, or via an ngrok URL for remote demos. No install required.
Chrome / Firefox :8082
ngrok (demo only)
External tunnel service. Forwards a temporary public HTTPS URL to the Dashboard Server during a demo. The URL changes each session; the robot is only reachable while the tunnel runs.
HTTPS → :8082 ADR-003
Jetson / ARM SBC
On-robot compute board. Runs the Dashboard Server (:8082) and a separate Camera Server (:8083), and connects to the USB camera, the RTL8761B BT dongle, and the OpenCM9.04. The gamepad is read locally via evdev in a thread inside the Dashboard Server.
:8082 / :8083 /dev/robot_camera /dev/opencm /dev/input/eventX
Bluetooth Gamepad
Machenike G3 V2, paired to the Jetson via the RTL8761B dongle. Paired/swapped from the dashboard with no terminal or sudo (ADR-013); read as a Linux evdev device (ADR-012).
RTL8761B 0bda:a760 evdev
OpenCM9.04
ROBOTIS microcontroller. Flashed with black_mata_firmware. Owns the Dynamixel TTL bus and runs an independent watchdog (ADR-008).
USB Serial 115200 baud Dynamixel2Arduino
AX-12A Servo Chain
8 servos daisy-chained on the Dynamixel TTL bus. IDs 1–4 steering (JOINT), IDs 5–8 drive (WHEEL).
1 Mbaud Protocol 1.0 IDs 1–8
